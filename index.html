Featured projects

shop_mcp_server

An MCP server in Rails that exposes a store's products, orders and inventory to Claude, with schema-validated tools, approval-gated writes, and semantic product search with Voyage AI embeddings and pgvector. Built on the official MCP Ruby SDK over Streamable HTTP.

Rails 8.1 · MCP Ruby SDK · PostgreSQL · pgvector · Voyage AI · RSpec

ai_shop_assistant

A shopping assistant that answers product questions from Shopify's live Catalog API over MCP, with realtime replies over Turbo Streams, background jobs on Solid Queue, and a hand-written JSON-RPC MCP client.

Rails 8 · RubyLLM · Google Gemini · Hotwire

product_geo_agent

An agent that rates how discoverable a Shopify product is to AI shopping assistants (GEO and AEO). It checks product data, FAQ content and schema.org structured data, asks an LLM whether it would recommend the product, and produces a deterministic score backed by an eval harness.

Rails · little_ghost · Google Gemini · Shopify Storefront API

support_engineer

A Rails 8 AI support agent that investigates orders and shipments, reads company policies, and asks a human before it acts. A learning project, built lesson by lesson.

Rails 8 · PostgreSQL · LLM agents
